## 🏗️ Moduli della Piattaforma

### MODULO 1 — CMS Proprietari (Supply Side)
Ogni proprietario accede a un pannello dedicato per gestire la propria struttura.

**Funzionalità:**
- Gestione annuncio: foto, descrizione, amenities
- **Smart Certification Checklist** — requisiti minimi per entrare nel brand:
  - WiFi ≥ 100 Mbps (verificato)
  - Scrivania dedicata
  - Monitor opzionale
  - Parcheggio
  - Pulizie settimanali incluse
- Calendario disponibilità
- Pricing engine: tariffa giornaliera / settimanale / mensile / 3 mesi
- Dashboard prenotazioni e revenue
- Messaggistica con smart worker

**Multi-tenancy:** ogni proprietario vede solo i propri dati.

---

### MODULO 2 — Booking Engine
Il motore di prenotazione è il cuore commerciale della piattaforma.

**Funzionalità:**
- Ricerca avanzata: città, date, budget, amenities, distanza dal mare
- Filtri smart-worker-specific: WiFi speed, scrivania, secondo schermo, silenziosità, pet-friendly
- **Long-stay pricing engine**: sconto automatico progressivo (7gg, 30gg, 90gg)
- Due modalità: Instant Book / Richiesta (a scelta del proprietario)
- Calcolatrice risparmio integrata: "Quanto risparmi vs. Milano"
- Integrazione Google Maps con distanze reali (superstrada, A14, servizi)
- Checkout sicuro con Stripe

---

### MODULO 3 — Smart Worker Portal (Demand Side)
L'esperienza del professionista che cerca una base operativa in Romagna.

**Funzionalità:**
- Profilo smart worker (professione, esigenze, preferenze)
- Ricerca e filtri avanzati
- Wishlist proprietà
- Storico soggiorni e recensioni
- Community board (opzionale fase 2): "Chi c'è a San Mauro questa settimana?"
- Notifiche: nuove proprietà, offerte last minute, eventi locali

---

### MODULO 4 — Admin Dashboard (NexaFrontiers)
Il pannello di controllo dell'operatore della piattaforma.

**Funzionalità:**
- Vista globale: tutte le proprietà, tutti i booking, tutto il revenue
- Gestione approvazione proprietà e certificazione Smart
- Commissioni e pagamenti: automatici via Stripe Connect
- Analytics: occupancy rate, RevPAR, CAC, LTV per città e per proprietà
- Marketing tools: SEO manager, email campaigns, LinkedIn post scheduler
- Gestione Comuni partner e co-marketing istituzionale
- Replica città: duplica l'intera struttura per nuova destinazione in <1 ora

---

### MODULO 5 — Marketing Engine
La macchina di acquisizione integrata nella piattaforma.

**Funzionalità:**
- Pagine SEO auto-generate per ogni proprietà e ogni città
- Blog CMS per contenuti smart working / vita in Romagna
- LinkedIn Content Scheduler con template per i proprietari
- Email marketing automation (onboarding, nurturing, retention)
- Open Graph ottimizzato per condivisione social
- Integrazione con Airbnb / Booking.com API per sync calendario
- Google Analytics 4 + Supabase Analytics dashboard unificata

---

### MODULO 6 — Automazioni n8n
Il sistema nervoso della piattaforma — elimina il lavoro manuale.

**Workflow automatici:**
- Nuova prenotazione → email proprietario + smart worker + Calendario Google
- Richiesta non risposta in 24h → reminder automatico proprietario
- Check-in avvenuto → trigger richiesta recensione (dopo 3 giorni)
- Proprietà non certificata → sequenza email onboarding
- Nuovo Comune partner → welcome kit automatico
- Pagamento commissione → invoice automatica

## 🛠️ Stack Tecnologico

```
Frontend:        Next.js 15 (App Router + RSC)
Database:        Supabase (PostgreSQL multi-tenant)
Auth:            Supabase Auth (proprietari + smart worker + admin)
Storage:         Supabase Storage (foto proprietà)
Payments:        Stripe + Stripe Connect (split automatico)
Email:           Resend (transazionale) + MailerLite (marketing)
Automazioni:     n8n (self-hosted)
Maps:            Google Maps API / Mapbox
Deploy:          Vercel (zero downtime, global CDN)
Analytics:       GA4 + Supabase Analytics
Monitoring:      Sentry + Vercel Analytics
CMS Blog:        Integrato in Supabase (no dipendenze esterne)
```

**Perché questo stack:**
- È lo stesso di YachtMe — esperienza reale, nessuna curva di apprendimento
- Supabase: multi-tenancy nativa, RLS per isolamento dati, storage incluso
- Stripe Connect: split automatico proprietario/piattaforma senza contabilità manuale
- n8n: già nella tua infrastruttura, zero costo aggiuntivo
- Vercel: deploy in 1 minuto, preview automatiche, scaling infinito

## 🔐 Principi Architetturali Non Negoziabili

**1. Multi-tenancy by design** — ogni nuova città si aggiunge in <1 ora, senza toccare il codice

**2. API-first** — ogni funzione è accessibile via API, la UI è un consumer come gli altri

**3. Zero vendor lock-in** — se Supabase o Vercel alzano i prezzi, migriamo in <1 settimana

**4. Privacy by design** — GDPR nativo: consenso granulare, portabilità dati, right to deletion

**5. Progressive enhancement** — funziona anche senza JavaScript (SSR puro per SEO perfetto)

**6. Observability** — ogni errore, ogni lentezza, ogni anomalia è tracciata prima che la veda il cliente
